# NUMERI RELATIVI!

PWA didattica per comprendere i numeri relativi attraverso due rappresentazioni equivalenti:

- **Ascensore**: positivo = salgo, negativo = scendo.
- **Retta dei numeri**: positivo = destra, negativo = sinistra.
- **Esercizi**: spostamenti guidati sulla retta da −10 a +10.

**Ideazione, progettazione didattica e programmazione originale in Scratch:** Prof. Flavio Naretti.  
**Conversione e sviluppo della versione PWA:** realizzati con il supporto di ChatGPT – OpenAI.  
La PWA mantiene Solly e Gabby, mascotte della scuola.

## PWA

La app usa un `id`, `scope`, cache e service worker dedicati a `numeri-relativi`, per evitare sovrapposizioni con altre PWA installate dallo stesso account GitHub Pages.
